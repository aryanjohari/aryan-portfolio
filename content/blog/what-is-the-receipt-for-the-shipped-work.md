For any work we ship, the receipt is clear: a live public web page and the specific code change that put it there. This means you will see the page on the portfolio website, along with the exact code commit in the `aryanjohari/aryan-portfolio` project that published it. These two items together prove the work is delivered and public.

### What We Ship

We publish public web pages on an existing portfolio site. Each page focuses on a specific type of content: a record of work done, a lesson learned, or a researched article. The goal is to clearly and factually show completed work.

### Our Shipping Process

We follow five clear steps to ensure every page is accurate and published correctly:

1.  **Choose:** We decide the type of page and its specific web address on the site.
2.  **Gather Facts:** We collect all information for the page. Every single fact must have clear proof. This proof comes either from the original work itself or a reliable outside source. This is the only step where new facts can be added.
3.  **Check Facts:** We review all gathered facts. If any fact lacks proof, or if the page uses bad practices like hidden text or misleading links, we stop the process. Only pages with verifiable facts and good practices move forward.
4.  **Write the Page:** We write the web page using *only* the facts that passed the check. We do not invent new information or add details not supported by proof.
5.  **Publish:** We add the completed page to our code project. This action creates a new, specific code change (a "commit"). Our site then automatically builds and publishes this change, making the page live on the internet.

### Proof of Delivery

The final "Publish" step creates the direct evidence of shipping. You will find the page at its public web address on the portfolio site. You will also find a specific code change (a "commit") in the `aryanjohari/aryan-portfolio` code project. This commit contains the exact page that went live. These two items together prove the work was shipped and is accessible to anyone.
