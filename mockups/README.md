# Mockups

The north star for the site's layout. Plain HTML, real colours and fonts, placeholder words.

- **Rule:** a layout change goes here first, Aryan approves it, then it goes into the site. Content edits go to `drafts/` instead.
- **Rough on purpose:** layout and look only. Not a second copy of the site.
- **Delete** once the live layout settles; the site becomes the north star.

Open with a local server so page-to-page view transitions work:

```sh
python3 -m http.server -d mockups 8000   # then http://localhost:8000
```

Pages: `index.html` (home), `project.html` (one project, Prism as the example).
